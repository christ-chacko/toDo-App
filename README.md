React Native To-Do App

A simple and responsive To-Do application built with React Native using Expo, Expo Router, Async Storage, Context API, and support for Light and Dark modes.

Features

• Add, edit, mark, and delete tasks
• Persistent storage using Async Storage
• Light and Dark mode support
• Global state management with Context API
• Organized navigation using Expo Router

Tech Stack

React Native • Expo • Expo Router • Async Storage • Context API

Installation

Clone the repository

git clone https://github.com/yourusername/todo-app.git


Navigate into the project directory

cd todo-app


Install dependencies

npm install


Start the Expo development server

npx expo start

Run on device

• Press a to open on Android
• Press i to open on iOS (Mac only)
• Press w to open in the web browser
